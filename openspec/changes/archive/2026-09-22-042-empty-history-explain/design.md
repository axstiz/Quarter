# Design: 042-empty-history-explain

planner.generate_plan уже пишет «не влезла в ресурс/SP/роли до конца квартала — кандидат на отмену» при capacity=0 и историю нет. Уточнение: добавить новый clear reason-文本 при не-наличии истории (истории нет), чтобы юзер понимал: нужно либо загрузить историю, либо вручную дополнить velocity; не изменяем семантику generate (спека 003).
