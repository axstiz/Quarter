# Design: 017-roles-sprint-view

## Контекст

Поведение уже реализовано и влито в develop (коммиты 7474da7, ff7056d). Спека закрепляет факт; сгенерировано по фактическому поведению фронтенда и решений лида:

- распределение оперирует **агрегатами ролей**, не персонами: у сервиса нет данных о назначениях, и per-person вид не должен притворяться планировочным решением (отклонён эксперимент «По людям», change 016 не трогаем);
- раскладка (placement) **единая на все виды** — хранится локально по planId; редактор один.

## Решения

1. **Агрегатный лимит роли** = Σ (80 ч × capacity_rate носителей) в команде. Заём выбирается детерминированно: команда с наибольшим свободным остатком лимита, при равенстве — по имени команды. Сравнение названий ролей — без регистра (нестыковки регистра в датасете известны).
2. **Часы ролей по частям** делятся пропорционально SP части (та же формула, что в «Загрузке»); размещение берётся из синхронной раскладки. Час глобальной потребности < 0,05 ч не показывается.
3. **Ручной перенос двигает роль-чип только как представителя всей части**: ключ раскладки — (task_id, исходный план-спринт части), чип лишь точка входа. Это исключает расползание ролей части по разным спринтам.
4. **Локальность переносов** — как и прежде: хранилище браузера, mock-режим; сохранение per planId, сброс кнопкой; на реальном бэкенсе редактор скрыт (read-only). Приоритетная правка «по-настоящему» — вкладка «Приоритеты» (PUT priority → recompute), это отдельный контур.
5. **Дефолтная вкладка** — roles без перезаписи URL: `current = view ?? 'roles'` (URL остаётся `/plan`, глубинные ссылки на `?view=sprints` работают).

## Риски и последствия

- Метры ролей могут показывать перегруз (>лимита) — это честный сигнал (раскладку двигал человек или лимиты носителей тоньше, чем потребность), не ошибка вида.
- Роли без задач, но с носителями, на экран не выводятся — плотность; полный перечень ролей и «дашборд дефицитов» остаётся во вкладке «Загрузка» (оставлена).
- Спека ситуаций, где пользователь ожидает per-person механизм, уводит фронт от него явно: подпись в UI обязательна.
