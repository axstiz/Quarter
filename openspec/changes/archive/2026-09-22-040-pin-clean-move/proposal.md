# Proposal: 040-pin-clean-move

## Why

После 032/038/039 у пинов накопилось три взаимодействующих слоя (deferred-регистрация, optimistic-копия чипа, бейдж, баннер) — юзер видит дубли/«копии» вместо простого переноса. Решение лида: пин — просто перенос чипа между колонками, сервер немедленно двигает данными (039), фронт перечитывает план — без optimistic-слоев, бейджей и баннеров.

## What Changes

- Фронт: удалить optimistic слой пинов (PlanPage клон модели), бейдж «пин», баннер неприменённых пинов и их state — drag → POST pin → refetch плана (сервер уже вернул целевую колонку)
- Сервер (039) остаётся: немедленное перемещение строк задачи + assignments; 409 по ёмкости; Done — 409

## Capabilities

### Modified Capabilities

- `ui` — «Единый редактор раскладки»: перетаскивание чипа SHALL отображаться как чистый перенос между колонками (немедленное серверное перемещение + refetch плана), без промежуточных optimistic-косов и бейджей.

## Impact
`frontend/src/features/plan/PlanPage.tsx`, `RolesView.tsx`, css — бэк не трогаем (039).
