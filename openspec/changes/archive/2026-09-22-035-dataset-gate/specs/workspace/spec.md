# Update capability: workspace

## ADDED Requirements

### Requirement: Гейтинг планирования до датасета

Плановые страницы (/plan, /sprint, /team-map, /metrics) SHALL требовать загруженный датасет в текущем workspace: если датасет не загружен, прогул по плановым роутам SHALL redirect'ить на /data с баннером «Загрузите датасет, чтобы пользоваться планированием». Страницы /data и /workspaces SHALL оставаться доступными всегда.

#### Scenario: Пустой workspace — редирект

- **GIVEN** выбран workspace без загруженного датасета
- **WHEN** пользователь заходит на /plan
- **THEN** редирект на /data, баннер о загрузке датасета; после подтвержении импорта все страницы открываются

#### Scenario: После confirm датасет загружен

- **GIVEN** датасет загружен (tasks > 0)
- **WHEN** переходы по NAV
- **THEN** все страницы доступны
