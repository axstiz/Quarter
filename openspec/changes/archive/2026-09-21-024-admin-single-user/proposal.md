# Change: 024-admin-single-user

## Why

Решение лида (2026-09-21, перед сдачей): ролевая модель в UI — лишняя поверхность для демо и жюри. Сервис демонстрируется одним пользователем-администратором: reader/editor-сценарии бэк всё равно энфорсит, а экраны «Участники» и «Права/аудит» без invite-механики (023) не показывают реального управления доступом. Мультитенантность (workspace-изоляция, X-Workspace-Id, роли на бэке) сохраняется полностью — упрощается только вход и UI-гейтинг.

## What Changes

1. **Вход одной кнопкой** (MODIFIED «Демо-вход»): экран входа — единственное действие «Войти как администратор» (`/auth/demo-login` с role=admin). Формы email/пароль и выбор ролей reader/editor/admin из UI убираются; JWT-вход остаётся на бэке без изменений.
2. **Роли не отображаются** (MODIFIED «Роль в интерфейсе»): бейджи ролей (сайдбар, карточки workspace) убраны; все UI-гейты `canEdit` выполняются (роль admin в сессии).
3. **Admin-экраны участников и прав сняты с UI** (REMOVED «Управление участниками (admin-экран)», REMOVED «Матрица прав и аудит (admin-экраны)»): маршруты `/workspace/people` и `/permissions` и их навигация удаляются; бэк-ручки `/workspaces/*/members`, `/permissions/*` остаются как есть (не используются фронтом; вернутся с 023/invite).
4. **Workspaces для одного пользователя** (MODIFIED «Смена компании в интерфейсе»): онбординг-экран и селектор workspace остаются (изоляция данных между пространствами нужна), но без ролевых пометок; создание workspace — без ролевого гейтинга.
5. Бэк и моки backend-ручек ролей/участников не меняются.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `auth`: MODIFIED «Демо-вход» — один демо-профиль admin, UI-формы email/пароля и выбора ролей убраны.
- `ui`: MODIFIED «Вход в сервис», «Смена компании в интерфейсе»; REMOVED «Управление участниками (admin-экран)», «Матрица прав и аудит (admin-экраны)».
- `workspace`: REMOVED «Матрица прав на экране», «Журнал аудита» (UI-слой); MODIFIED «Экран выбора рабочего пространства» (без ролей).

## Non-goals

- Изменения бэкенда: роли, membership, матрица прав и аудит на API остаются как есть.
- Удаление мок-хендлеров участников/прав (могут пригодиться 023/invite).
- Invite по email/ссылке — change 023.
