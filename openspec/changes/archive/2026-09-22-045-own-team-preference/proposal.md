# Proposal: 045-own-team-preference

## Why

Займы из других команд слишком часты (64.9% назначений): `_put_hours` сортировал инженеров только по свободным часам, без учёта команды задачи — даже 1 свободный час чужой команды использовался до свободного своего носителя. Людям тяжело работать при таком распределении (лид).

## What Changes

- `_put_hours` (planner + ступень 2 solver): сортировка носителей — сначала pinned/preferred, потом инженеры **своей команды задачи** по свободным часам, потом заёмные; заём берётся только при нехватке своих в спринте
- `eng_teams` (команда инженера) прокидывается в оба пути (generate_plan, allocate_engineers)
- Generate-раскладка: доля займов 64.9% → 53.3% (QA-замер); solver — без изменений (займы там объективная нехватка своих — Team-Platform заняты на 75–79/80 ч)

## Capabilities

### Modified Capabilities

- `planning` — приоритет своей команды задачи при закрытии ролевых часов; заём только при нехватке своих.

## Impact
`src/services/planner.py`, `src/services/optimize_plan.py`, тесты.
