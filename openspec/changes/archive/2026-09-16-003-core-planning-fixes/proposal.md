# Change: 003-core-planning-fixes

## Why

Диагностика change 001/002 показала: из 45 задач planner планирует только 2 (43 postponed с причиной «не хватает ресурса/ролей»). Правильно : задача требует роли, которой в команде нет (например «Архитектор решений» только в Team-Platform при задачах Team-L). По ТЗ это корректный отказ, но в реальной жизни resource-менеджер берёт специалиста кросс-командно — иначе демо показывает пустой план, и приоритетные задачи не определяются. Также не применены статусы (Done в плане), приоритеты (человеко-центричная prioritization — решение v0.2), переотмена/confirm-cancel и метрики не по инициативам.

## What changes

1. **Кросс-командный заём ролей**: требуемая роль задачи может закрываться инженером из другой команды; суммарные обязательства инженера по всем командам ≤ его лимита (80 ч полная ставка, 40 ч при 0.5), отдельная функция capacity.
2. **Статусы**: Done — вне планирования; InProgress — остаток `estimated_hh − spent_time` с пропорциональным остатком SP (если spent_time ≥ estimated_hh — задача помечается отметкой «просрочена» (overdue) и планируется хвостом); ToDo — полный объём.
3. **Приориты**: поле `priority` (integer) в задаче; seed: `planned_in_sprint='Да'` favored (низкое число → высокий приоритет), прочим — исходный порядок файла; приоритет торжественно используется planner'ом (human-in-loop UI появится в change 004-frontend/adapter).
4. **Отмена с подтверждением**: planner 选 отмену-кандидаты (не поместилась даже в спринт 6) с причиной; ручки: POST /plans/{id}/tasks/{task_id}/cancel-request, POST /plans/{id}/tasks/{task_id}/cancel-confirm; отменённые не теряются.
5. **Метрики по инициативам**: знаменатель — инициативы с ≥1 задачей в первоначальном плане; числитель — инициативы, у которых все их запланированные задачи done_actual к концу квартала.

## Non-goals

- UI приоритетов (drag-n-drop) — change 006 (фронт); ручка — здесь.
- Снапшоты версий планов — change 007; до него знаменатель метрики держится от обновления плана (merge意识地 не пересоздаёт initial plan).
- Bus-виджет — change 004-bus (в серии).

## Risks

- Кросс-командное заём скрывает реальную нехватку ролей на уровне компании: warn-уровень остаётся дефицит-роль при поездке роли через teams — предупреждение показываем (role_deficit уже есть).
- «Итого по ролям» в матрице — исключены при импорте (было найдено в change 002b) — Будьте осторожны с новыми xlsx с другими итоговыми строками.
