# Proposal: 036-multi-upload

## Why

Загрузчик принимает только один файл (input без `multiple`), длинный импорт без пофайловой видимости и понятной очередности — юзер жалуется: «нельзя сразу выбрать несколько файлов, долго грузится».

## What Changes

- Импорт-страница: `<input multiple>`; несколько выбранных файлов грузятся ПОСЛЕДОВАТЕЛЬНО (по одному enqueued job'у, чтобы не штурмовать воркер), каждый строкой в списке с собственным статусом job (uploaded → mapping → questions|ready) и тостом
- Ошибки — per-file (сбой одного файла не валит весь список), confirm остаётся кей-поверх импорта (merge по ключам, change 025 идемпотентен)
- Спек-дельта `data`/`ui`: последовательный enqueue, merge по ключам подтвержден.

## Capabilities

### Modified Capabilities

- `data` — загрузка SHALL поддерживать несколько файлов последовательно (per-file job, merge по ключам при confirm)
- `ui` — список файлов с per-file статусами job'ов

## Impact
`ImportPage.tsx` (input multiple, очередь), `queries.ts` (мутация list), бэк не трогаем (028 идемпоцent chịu).
