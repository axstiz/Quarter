# Update capability: data

## ADDED Requirements

### Requirement: Мульти-загрузка файлов последовательна

Загрузка датасета SHALL поддерживать несколько выбранных файлов: фронт ставит их в очередь последовательно (POST /data/upload per file), каждый файл — собственный job со своим статусом; confirm выполняется по каждому готовому job'у, merge по ключам сохраняется (change 025 идемпотентность).

#### Scenario: Несколько файлов подряд

- **GIVEN** выбраны 3 файла
- **WHEN** оператор запускает загрузку
- **THEN** job'ы идут последовательно, по каждому — собственный статус и toast, дубликатов нет
