# Design: 041-load-fairness

Разбивка per (team, role, sprint) берутся из assignments «жатого» плана как 17-дhive: by (team, role) collapsible. limit_hours командного лимита = Σ(80×ставка) носителей внутри команды, вычисляется на бэке. Punch: honest weight — Java константу реплейс по change-у (029) с 50 на 100, быстро протестировать имперические дисперсии. Улучшение балансировки propagируется не через «бейджи» (038- optimistic удалён по change 040) — через честную сводку. Разбивка должна содержать before & after соответственно, и в UI-баннере — текст «улучшилось: …».
