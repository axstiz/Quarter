# Update capability: planning

## ADDED Requirements

### Requirement: Концентрация займа в одной донорской команде

При займе ролевых часов из других команд сервис SHALL закрывать часы из **одной донорской команды** с максимальным суммарным свободным лимитом роли в данном спринте; при её нехватке — из **одной запасной** (второй по лимиту); третья и последующие команды SHALL NOT использоваться — остаток часов переносится в следующий спринт. Виртуальные держатели ролей без носителей и pinned/preferred-инженер этим ограничением не затрагиваются.

#### Scenario: Займ из одной донорской

- **GIVEN** задача требует 100 ч роли, своя команда не может закрыть, донорские команды B (160 ч свободно), C (40 ч), D (30 ч)
- **WHEN** планирование
- **THEN** все 100 ч закрываются инженерами команды B, команды C и D не затрагиваются

#### Scenario: Запасная донорская при нехватке первой

- **GIVEN** задача требует 100 ч роли, донорская B даёт 60 ч, запасная C — 50 ч, есть ещё D (40 ч)
- **WHEN** планирование
- **THEN** 60 ч — команда B, 40 ч — команда C; команда D не используется

#### Scenario: Отложка при нехватке двух донорских

- **GIVEN** задача требует 150 ч роли, донорские B (60 ч) и C (50 ч) суммарно дают 110 ч, есть ещё D (40 ч)
- **WHEN** планирование
- **THEN** в спринте размещается 110 ч из B и C; остаток 40 ч переносится в следующий спринт, команда D не используется
