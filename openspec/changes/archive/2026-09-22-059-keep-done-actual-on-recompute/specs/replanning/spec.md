# Update capability: replanning

## ADDED Requirements

### Requirement: Пересчёт сохраняет выполненные по прошлым фактам задачи

При создании новой версии плана после загрузки факта сервис SHALL копировать в неё строки со статусом `done_actual` из текущей версии (спринт, причина, SP, назначения) — выполненные по прошлым фактам задачи не исчезают из ганта и представлений загрузки при последующих пересчётах.

#### Scenario: Факт второго спринта

- **GIVEN** версия B содержит задачу X со статусом done_actual в спринте 1 (факт 1-го спринта)
- **WHEN** загрузка факта 2-го спринта создаёт версию C
- **THEN** версия C содержит задачу X со статусом done_actual в спринте 1 и задачи, выполненные по факту 2-го спринта, — в спринте 2
