## Context

Importer в текущем коде валидирует наличие reference_values.csv и task_role_hours.csv, но не импортирует их (src/db/importer.py: FILES — только проверка). Задание требует объяснять причины расхождения планов. Сопряжено с фиксом reset_dataset_tables (в текущем коде повторный импорт уничтожает планы — готовится отдельный фикс-change).

## Goals / Non-Goals

**Goals:**
- Полный импорт 7 файлов датасета (справочники и фактические часы по ролям перестают быть «фичей только на бумаге»)
- Витрина фактических часов по ролям на карточке задачи
- Понятные причины расхождений на основе справочных категорий

**Non-Goals:**
- Использование task_role_hours в planner (расчёт произвольной производительности по ролям — нет данных после 6 задач)
- Изменение dataset/*.csv

## Decisions

- **task_role_hours — только витрина** (cardinality: данные есть у 6 из 45 задач; любого расчёта не хватит для честных выводов) — решение лида (2026-09-17), фиксируется в README как допущение
- **Справочники — импортная таблица без ручных правок** (source=imported), повторный импорт обновляет целиком; категория причин расхождения привязывается текстом в reason/warning (MVP: простое сопоставление категории по типу предупреждения)
- **Новое поле role_hours_actual в карточке задачи** — только JSON в ответе, без изменения схем планирования

## Risks / Trade-offs

- Связь с фикс-ом reset_dataset_tables: справочники — импортная таблица, тоже должна очищаться им; координировать изменения при реализации (в одном проходе бэкендера)
