# Design: 038-pin-optimistic-ui

Optimistic слой живёт ТОЛЬКО фронтом: клонирование строк затронутой задачи (sprint_no = цель) в модели до рулболда — downstream-расчёты не знают об optimistic. Слой хранится в PlanPage (переключение видов — только отображение одной модели), сбрасывается: после успешного recompute, при смене plan_id, при unpin этой задачи. Ошибки pin — слой не применяется. SP/часы: колонка теряющий задачу теряет её SP/часы метрика полной модели downstream. Виртуальные/"due" чипы не двигаются (валидация на клиенте до POST). Риск зерkala с pin 409 — чип не двигается (error path). На пересчёте данные сервера приходят и слой сбрасывается; поверхность реакций остаётся прежней.
