# Delta capability: ui

## ADDED Requirements

### Requirement: Вкладка прогноза рисков

Звёздная карта SHALL иметь вкладку «Прогноз рисков» (view=forecast) на данных `GET /plans/{plan_id}/bus-forecast`: таблица людей с плановой загрузкой — человек (переход в профиль инженера), команды и роль, загрузка по спринтам (визуально к личному лимиту, перегруженные спринты отмечены), критичные роли (единственный носитель, бейдж), уровень риска (high/medium/low как бейдж) и основание-текст с числами; для каждого человека формулировка «если уйдёт: N задач / M ч» — прогноз потерь плана. Данные ручки строятся на версии плана — инвалидируются вместе с планом (при пересчёте/факте). Пока плана или загрузки нет — пустое состояние с пояснением; ошибка ручки показывается как ошибка вкладки, не «рисков нет».

#### Scenario: Просмотр прогноза

- **GIVEN** построен план с загрузкой людей (assignments)
- **WHEN** пользователь открывает «Звёздная карта» → «Прогноз рисков»
- **THEN** таблица содержит инженеров с загрузкой, отсортированных по уровню риска и объёму; клик по человеку открывает его профиль

#### Scenario: Пустое состояние

- **GIVEN** плана в workspace нет (или ни у кого нет плановой загрузки)
- **WHEN** открыта вкладка «Прогноз рисков»
- **THEN** показано пояснение («нет плана — постройте план, чтобы увидеть прогноз» / «загрузки нет»), а не нулевые строки
