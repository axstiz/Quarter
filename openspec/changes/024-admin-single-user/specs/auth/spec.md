# Delta capability: auth

## MODIFIED Requirements

### Requirement: Демо-пользователь

Сервис SHALL предоставлять демо-вход одним действием «Войти как администратор»: фронтенд вызывает `/auth/demo-login` с `role=admin`. Экран входа SHALL NOT предлагать выбор ролей (reader/editor) и форму email/пароля — единственный UI-путь входа в демо — демо-админ. Серверная ролевая модель, JWT-ручки `/auth/login`, `/auth/register` и все права остаются без изменений (UI их не использует).

#### Scenario: Единственная кнопка входа

- **GIVEN** пользователь на экране входа
- **WHEN** он нажимает «Войти как администратор»
- **THEN** создаётся сессия с ролью admin и открывается онбординг-экран выбора workspace

#### Scenario: Демо-вход

- **GIVEN** пустая БД пользователей
- **WHEN** POST /auth/demo-login
- **THEN** сессия демо-лида, пользователь появляется в списке, правки работают
