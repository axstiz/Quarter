# Update capability: planning

## ADDED Requirements

### Requirement: Закрепление части задачи

`POST /plans/{id}/tasks/{task_id}/pin` SHALL принимать необязательное поле `from_sprint_no`. Если оно задано, SHALL перемещаться только строка задачи из спринта `from_sprint_no` (её SP и assignments), остальные части задачи остаются на своих спринтах; если строки задачи в этом спринте нет — 404. Без `from_sprint_no` перемещаются все строки задачи (прежнее поведение). После перемещения все строки задачи в целевом спринте SHALL сливаться в одну: `planned_sp` суммируется, assignments объединяются с `sprint_no` целевого спринта, лишние строки удаляются — в версии плана не бывает двух строк одной задачи в одном спринте. Закрепление (`pinned_sprint`) ставится на пережившую строку. Проверки границ квартала, факта (`done_actual` → 409), зависимостей и ёмкости инженера сохраняются; ёмкость считается по часам перемещаемой части. `DELETE .../pin` снимает закрепление со всех частей задачи.

#### Scenario: Перенос одной части

- **GIVEN** задача размещена частями в спринтах 2, 3 и 4
- **WHEN** POST pin `{sprint_no: 2, from_sprint_no: 4}`
- **THEN** в спринте 4 задачи больше нет, часть из спринта 3 на месте, в спринте 2 — одна строка задачи с суммой SP обеих частей и assignments с `sprint_no = 2`

#### Scenario: Нет части в исходном спринте

- **GIVEN** задача размещена только в спринте 2
- **WHEN** POST pin `{sprint_no: 3, from_sprint_no: 5}`
- **THEN** 404, план не меняется

#### Scenario: Перенос всей задачи

- **GIVEN** задача размещена частями в спринтах 2 и 3
- **WHEN** POST pin `{sprint_no: 2}` без `from_sprint_no`
- **THEN** у задачи одна строка в спринте 2
