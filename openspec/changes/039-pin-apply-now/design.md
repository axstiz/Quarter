# Design: 039-pin-apply-now

Оберrouting.pin: строки одной задачи (PlanItemORM) переносятся на целевой спринт; assignments JSON — каждому инженеру task-строки ставится sprint_no=целевой (перемещение части целиком, spec ui). Ёмкости pre-check: только для назначений task (не cross-командный заём) — sum hours in target sprint per engineer+job>limit → 409. Конфликт ёмкости без пересборки весь план; только про пользователя чек. change 032/038 либо дополняются новой семантикой: optimistic UI согласуется с немедленным сервером (одна раскладка). Замечание для презентации: пин немедленный, часть задачи перемещается точечно; пересборка/оптимизация остальное поже download.
