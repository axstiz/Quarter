# Update capability: data

## ADDED Requirements

### Requirement: Display-имена ролей в данных и назначениях

Фактические часы ролей (`task_role_hours`) SHALL импортироваться с display-именами ролей: машинные имена колонок секции часов xlsx («разработчик_java») маппятся на display-имена из секции требований («Разработчик Java») по каноническому ключу (игнорируя пробелы, подчёркивания, скобки, слэши, регистр); колонки без маппинга сохраняются как есть. Assignments оптимизированного плана SHALL содержать display-имя роли из данных задач/инженеров, а не нормализованный ключ части solver.

#### Scenario: Импорт фактических часов

- **GIVEN** xlsx с колонкой «тестировщик_автотестирование» в секции часов и ролью «Тестировщик (Автотестирование)» в секции требований
- **WHEN** импорт датасета
- **THEN** фактические часы записаны с ролью «Тестировщик (Автотестирование)»

#### Scenario: Assignments оптимизации

- **GIVEN** часть solver с нормализованным ключом роли «тестировщик(автотестирование)»
- **WHEN** ступень 2 закрепляет часы за инженерами
- **THEN** assignment содержит role «Тестировщик (Автотестирование)»
