# Design: 034-busy-veil

Оверлей рендерится на уровне страницы (не app-level — решено: не мешать соседней навигации). Флаг busy = ; плюс aria-live polite для скринридера. Для свежего статуса optimize poll — мутация может хранить последний прочитанный статус job'а в mDataq (последний poll результат) → берём через optimize.variables/ просто задействуем новый text из data из polling: используем optimize.data (последний polled job) для статуса.
Простой путь: показ статуса «Solver работает…» без детального job-статуса (poll для тоста уже есть); при желании можно вывести реш colorful — но (по дизайну) минимальный объём: два статуса (queued→solving не обязательно различимы на кнопке, но у нас polling валиден).
